## Database Mapping Notes

### compound_groups table
- Represents the DISPLAY hierarchy (sections/subsections)
- Examples: "Vitamins", "Fat-Soluble Vitamins", "B-Complex"

### compounds table
- `groupId` → links to compound_groups for display organization
- `parentCompoundId` → links to parent compound for roll-up calculations
- `tier` → 'core' or 'advanced'

### Parent-Child Relationships
Parent compounds (e.g., "Vitamin A (RAE)") aggregate their children:
- Retinol, Beta-Carotene, etc. → roll up to Vitamin A (RAE)
- Individual saturated fats → roll up to Saturated Fat (total)
- Individual B vitamins don't roll up (B-Complex is a display group, not a compound)
