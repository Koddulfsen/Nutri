## Component Code System

BLS 4.0 uses **EuroFIR/INFOODS standard codes** similar to other European databases.

### Key Features
- Full amino acid profile (19 amino acids)
- Detailed fatty acid breakdown (36 fatty acids)
- Fiber subfractions (HMW, LMW, soluble, insoluble)
- Vitamin subtypes (D2/D3, K1/K2, tocopherols/tocotrienols)
- Organic acid breakdown
- German and English names provided
